# 凯伊桌宠全量语音资源库与功能调用指南

## 1. 范围与命名规则

依据：此前七张 Kivo 语音分类截图、原《语音与音效需求清单》及最新七项功能截图。共149个截图可见编号（含1条仅见编号的 battle_damage_1），未扫描用户本地音频，不保证与实际下载文件完全一致；截图截断内容不补写。本文仅给语义摘要，不是正式字幕。

来源：https://kivo.wiki/data/character/518?mode=voice

A=优先候选，B=低频/特定场景候选，C=原声收藏或待核验，不进入自动调用池。A 58条、B 38条、C 53条。尚未试听，所有情绪、时长、音质均需核验。

命名采用 VO_类别_序号.ogg，尽量保留上一版65条映射；原需求中未分配实体的 ID 不等于必须存在的文件。每个原始编号只对应一个实体文件。若实际音频不是 OGG，保留真实扩展名或转码。不要直接改扩展名。功能事件与文件名分开，用配置引用同一音频，不复制。

网站来源统计：养成 10条；大厅 57条；战斗 29条；咖啡厅 5条；活动 45条；编队 3条。其他为空。

## 4. 额外资源利用：原声鉴赏与组合对白

C级53条仍有明确编号与目标名，但不进入随机播放池。剧情片段可按原始编号顺序在手动鉴赏页播放（如 memoriallobby_1_1 → 1_2；lobby_1_1 → 1_4；生日 player_1 → player_7）；停顿片段只能用于原顺序，先试听确认。无线电版本保留独立文件，与普通版本不混入同一池。battle_damage_1 必须先听再判断，不补写内容。剧情、较重警告、涉及其他人物或承诺的台词仅供原声查看。

## 5. 播放与接入规范

- 同一事件选择一个文件、一个表情和对应字幕；正式字幕按实际录音核对。摘要不可当逐字字幕。
- 普通点击语音建议设概率与全局冷却（例如20%与8秒，后续实测调整）；提醒优先于普通交互；拖拽取消时停止关联语音。
- 待机和行走默认静音；用户可选择开启低频独白。长句允许卡片延长至语音结束。
- 保留原始文件备份；核验格式、时长、是否含滤镜、授权后再启用。公开发布前核实原作音频使用及再分发许可。
- 好感度为游戏进度，不因用户离线或拒绝互动扣减；不主动播放带关系压力的对白。
