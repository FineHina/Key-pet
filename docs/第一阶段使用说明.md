# 第一阶段使用说明：番茄钟、提醒、勿扰和互动语音

> 更新：2026-11-24。番茄钟、提醒、勿扰、互动语音已实现；快捷工具与本地陪伴对话/日期彩蛋也已加入，见[快捷工具与陪伴对话说明](快捷工具与陪伴对话使用说明.md)。养成、小游戏和联网AI仍未实现。

## 启动与入口

先右键退出旧桌宠，再双击项目的 `启动桌宠.bat`。右键桌宠或托盘→「桌宠助手」打开面板，包含「专注计时」「提醒」「声音/勿扰」三个页签。

新增“陪伴对话”和“快捷工具”两个页签，使用方法见[快捷工具与陪伴对话使用说明](快捷工具与陪伴对话使用说明.md)。

桌宠使用本地锁文件防止重复运行；旧版本实例不认识这个锁，所以升级时仍需先手动退出旧实例。不会自动结束其他进程。

## 1. 番茄钟

- 支持25/45/60分钟或自定义专注时间，休息5/10分钟或自定义。
- 开始后可暂停、继续、取消；同时只允许一个专注或休息计时。
- 结束后显示持久通知，可确认或开始休息；不会自动开始下一轮专注。
- 倒计时与提醒由独立服务检查，隐藏桌宠、关闭助手面板不会暂停它们。
- 退出/重启会恢复活动会话；电脑睡眠后校正已过去时间。
- 当前托盘提示显示计时和待处理数量。

## 2. 提醒

在「提醒」页输入内容，选择“多少分钟后”或具体日期时间。支持新增、编辑尚未到期提醒、取消、完成和稍后5/10分钟或自定义。

到期事项进入持久待处理列表，有独立可操作通知窗口。不是只显示5秒的普通图文卡片，关掉通知窗口也不会把事项标成已完成。

提醒、计时和通知记录保存在 `data/assistant.sqlite3`；不要在运行时删除数据库。

## 3. 勿扰与静音

- 托盘「勿扰模式」即时切换手动勿扰。
- 「声音/勿扰」页可启用定时勿扰（默认23:00–08:00，可改），支持跨午夜。开始结束相同表示全天勿扰。
- 可选全屏抑制：当前前台全屏应用时减少打扰；默认关闭。
- 勿扰会停止声音并阻止主动提醒弹窗，计时和提醒继续记录。
- 主动点击桌宠仍可看到无声图文反应。
- 取消勿扰不会批量补播旧语音、旧通知；在助手面板查看待处理数量和事项。
- 静音只影响声音，不影响提醒窗口。可以分别关闭互动语音或调整音量（默认35%）。

## 4. 互动语音

本地 `voices` 有152个OGG文件，均可解码。全量指南对应149条，另3条战斗喊声归未分类C收藏。当前22个场景映射覆盖38个独立语音，精选自动池只使用A级；所有152条可在鉴赏列表查看。详情见[语音分类核对报告](语音分类核对报告.md)。

普通点击、双击、长按、拖拽和连续戳动使用适配语音；同一池尽量避免连播重复。一时只播一条，普通互动约3秒冷却，拖拽/悬停更长，不积压队列。专注完成等通知有更高优先级，播放期间保留对应图文，普通点击不会截断；手动停止、静音、勿扰和退出始终生效。

卡片**只显示对应中文文本**，不显示“素材清单译文（未试听核验）”前缀。来源与核验状态记录在文档/清单，不冒充逐条人工确认。功能状态文字与语音中文可一起显示；长语音延长卡片时间。

- 专注开始、暂停/开始休息、继续、专注完成和休息结束使用不同候选池。
- 实际完成提醒后可播一次肯定反馈；重复确认不会重播。到期/保存/延期/错误无准确原声，继续文字提示。
- 主动打开助手可有语音回应，面板刷新不触发；设置里可关闭。
- 黑脸和哭泣自动静音。黑脸重警告等C素材只供手动鉴赏，不进入自动池。
- 悬停语音和低频待机独白默认关闭；可在设置开启。待机独白至少约3分钟一次，仅在没有专注/提醒/其他语音且未静音勿扰时尝试。
- 「全量语音鉴赏」支持分类、A/B/C等级、中文/原编号/VO别名搜索，原文件不改名。可以试听/停止全部可用素材。
- 手动“问候、鼓励、休息建议”入口使用适配主题池，不是AI动态对话。
- 无独立SFX素材，不把原声喊话当铃声或错误音。
- 源音频只读不上传，长自我介绍和剧情不自动播放；公开发布仍需核实素材许可。

## 5. 保留的桌宠行为

原立绘差分、Q版原脸、上方图文卡片（默认图片108px、文字14px）、拖拽、缩放、四组视频动作不变。双击身体仍可播放动作1；原地行走不会移动窗口。

设置保存在 `config.json`。保存声音设置与拖拽位置都采用合并保存，不相互覆盖。

## 6. 核验与限制

已通过：本地OGG元数据解码、Qt静音播放、短时专注和提醒、勿扰、隐藏窗口后提醒继续运行、重复扫描去重、持久化恢复和旧桌宠回归。

未宣称完成：每条语音的人工听感、中文翻译准确性、背景声或情绪强度审核。请用试听面板确认后调整素材映射。


`smoke_audio.py`为静音播放；`smoke_assistant.py`使用临时配置和数据库，不写入真实任务。
