# KEI Assistant 项目技术架构

KEI Assistant 是一个面向 Windows 10/11 的本地桌宠和桌面助手。它在同一个 Python 进程内运行 Q 版桌宠、系统托盘、助手面板、小游戏和本地语音。陪伴对话用固定话题与关键词匹配本地台词，整个应用无需部署服务端。

## 技术栈

| 领域 | 当前实现 |
| --- | --- |
| 语言与启动 | Python 3.10+。入口是 [main.py](../main.py)，Windows 下也可以双击 [启动桌宠.bat](../启动桌宠.bat)，由 `pythonw` 启动。 |
| 原生桌面 UI | PySide6（Qt 6），依赖声明为 `PySide6>=6.6`。Qt Widgets 负责界面和托盘，QSS 与 `QPalette` 负责主题，`QSvgRenderer` 绘制图标与装饰。 |
| 桌宠渲染 | `QPainter`、`QImage` 和 NumPy。用透明 PNG 分层绘制角色，也能按清单播放透明 PNG 序列帧。运行时命中检测读取图像的 Alpha 数据。 |
| Windows 接入 | Python 标准库 `ctypes` 调用 Win32 API，实现透明区域鼠标穿透、前台窗口全屏检测和原生标题栏配色。 |
| 角色语音 | Qt Multimedia 的 `QMediaPlayer` 和 `QAudioOutput` 播放 `voices/` 内的本地 OGG。 |
| 数据存储 | Python 标准库 `sqlite3` 持久化业务数据。JSON 用于本机偏好、气泡文本和资源清单。 |
| 素材处理与测试 | Pillow、imageio、imageio-ffmpeg 主要用于离线处理和检查素材。部分素材脚本还需要 SciPy，应用启动无需安装它。自动测试使用标准库 `unittest`，Qt 测试可使用离屏平台。 |

依赖以 [requirements.txt](../requirements.txt) 为准。项目已包含全部运行素材，克隆后即可使用。安装及启动命令都从项目根目录执行。

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 启动和事件流

1. `main.py` 创建 `QApplication`，用 `data/desktop-pet.lock` 上的 `QLockFile` 保证单实例运行，再创建 `PetWindow`。
2. `PetWindow` 组装桌宠渲染、手势识别、行为状态、反应卡、托盘和 `AssistantController`。主入口先尝试发放当日礼物，再显示桌宠，通过 `QTimer.singleShot(0, ...)` 调度启动问候。
3. 桌宠鼠标事件经过 `Gestures` 识别，经同步的 Python `EventBus` 交给 `Behaviors`，并通知控制器处理声音或好感度。桌宠的帧更新和鼠标命中轮询分别配置为 16 ms 和 30 ms。绘制完成后，窗口保留该角色帧，用于后续鼠标命中和原立绘反应卡定位。
4. 助手界面通过 `AssistantController` 调用业务服务。控制器用 Qt 信号通知窗口刷新，并每 250 ms 检查专注、提醒、日历及自动语音。业务计时基于时钟与截止时间，`QTimer` 用来调度检查。
5. 关闭助手窗口后仍可从托盘打开。用户选择退出时，控制器关闭计时器、音频和数据库连接。

## 功能和代码入口

| 功能 | 从哪里读代码 | 核心行为 |
| --- | --- | --- |
| 桌宠窗口、托盘、右键菜单 | [window.py](../pet/window.py)、[gestures.py](../pet/gestures.py)、[behaviors.py](../pet/behaviors.py) | 无边框、透明、置顶、不主动抢焦点。支持点击、双击、长按、悬停、连戳、拖动、缩放。根据当前画面命中头部或身体，分层渲染时光环按身体处理，透明区域允许鼠标穿透。 |
| 动作与反应卡 | [scene.py](../pet/scene.py)、[character_renderer.py](../pet/character_renderer.py)、[animations.py](../pet/animations.py)、[reaction_card.py](../pet/reaction_card.py) | `PetScene` 为原版 Q 版头部、身体和光环计算程序化变换，也能播放 PNG 序列帧。窗口用同一角色帧绘制和判定命中。独立反应卡显示原立绘差分及台词。 |
| 五个助手页面和主题 | [assistant_panel.py](../pet/assistant_panel.py)、[companion_pages.py](../pet/companion_pages.py)、[ui_theme.py](../pet/ui_theme.py)、[ui_widgets.py](../pet/ui_widgets.py) | 页面包括专注计时、事项提醒、声音设置与勿扰、陪伴对话、快捷工具。主题支持浅色、深色和跟随系统，滚动容器、间距、图标和通用控件集中实现。 |
| 专注、休息和事项提醒 | [focus.py](../pet/focus.py)、[reminders.py](../pet/reminders.py)、[notification_window.py](../pet/notification_window.py) | 专注支持开始、暂停、恢复、取消与重启后恢复。事项可以指定日期时间或若干分钟后，支持编辑、完成和稍后提醒。到期记录由独立通知窗口展示。 |
| 静音、语音和勿扰 | [audio.py](../pet/audio.py)、[notification_policy.py](../pet/notification_policy.py)、[voice_manifest.json](../voice_manifest.json) | 按场景筛选有效语音，自动播放通常用 A 级条目，并控制最近重复、冷却与播放优先级。手动勿扰、跨午夜静默时段和前台全屏检测统一经通知策略判断。 |
| 陪伴对话、启动问候与彩蛋 | [dialogue.py](../pet/dialogue.py)、[calendar_events.py](../pet/calendar_events.py)、[assistant.py](../pet/assistant.py) | 本地话题、关键词和固定回退文本。启动时判定是否可播，特殊日期优先于普通问候。日期有元旦、万圣节、圣诞节和用户生日，生日优先，自动彩蛋按本地日期记一次触发或跳过。 |
| 快捷工具 | [shortcuts.py](../pet/shortcuts.py)、[companion_pages.py](../pet/companion_pages.py) | 保存应用、文件、文件夹和网页入口。应用经 `QProcess.startDetached` 启动，其余通过 `QDesktopServices` 打开。目标校验在服务层。 |
| KEI 互动 | [interaction_window.py](../pet/interaction_window.py)、[interaction.py](../pet/interaction.py)、[interaction_feedback.py](../pet/interaction_feedback.py) | 维护 0–100 好感度、限时心情和礼物库存。喂食可选蛋糕、冷奶茶、热奶茶，也能让凯伊休息或送礼。照顾和送礼可以连续操作，好感计分有分类上限，语音另外受播放策略约束。 |
| 小游戏与翻牌 | [mini_games.py](../pet/mini_games.py)、[game_windows.py](../pet/game_windows.py)、[interaction.py](../pet/interaction.py) | 规则与界面分离。鼠标猜拳、1–100 猜数字和光环记忆在完成一场后产生三张礼物牌，可逐张领取。每天首次启动也会直接入库一件随机礼物。 |

助手与桌宠的连接点是 [AssistantController](../pet/assistant.py)。以送礼为例，`InteractionWindow` 调用 `give_kei_gift()`，`InteractionService.give()` 在事务内扣库存、更新心情和好感度。提交后，控制器发出 `interaction_changed`，再用 `interaction_feedback.py` 的配置请求动作、表情、字幕和语音。勿扰或音频占用可以抑制表现，已经成功的业务操作仍然有效。

## 数据与资源

| 位置 | 内容与读取方式 |
| --- | --- |
| `data/assistant.sqlite3` | 由 [Storage](../pet/storage.py) 创建和迁移，当前 `SCHEMA_VERSION = 4`，通过 `PRAGMA user_version` 跟踪。保存专注会话、提醒、通知、快捷工具、日历记录、好感与心情、得分和礼物。 |
| `config.json` | 由 [config.py](../pet/config.py) 加载和校验，记录位置、缩放、主题、语音、生日月日、勿扰及默认时长。保存时合并偏好并原子替换文件。缺少文件时使用代码中的默认值。 |
| [bubbles.json](../bubbles.json) 与进程内对话历史 | JSON 保存按互动或表情分类的桌宠气泡文本。陪伴对话历史由 `DialogueService.history` 在当前进程内保留最近 30 条。 |
| `assets/layers/` 与 `assets/differentials/` | 本地 Q 版透明分层 PNG 和原立绘差分 PNG，分别供桌宠本体和反应卡绘制。 |
| [assets/animations/manifest.json](../assets/animations/manifest.json) | 446 × 602 透明序列帧清单，包含片段 ID、播放模式、待机标记、每帧时长和可选头部遮罩。右键预览提供原始四组动作，真实送礼调用 `receive` 程序化动作或好感里程碑动作。 |
| [assets/character/kei/](../assets/character/kei/)、[assets/ui/kei/](../assets/ui/kei/) 与 [assets/interaction/kei/](../assets/interaction/kei/) | 助手界面角色素材、SVG 装饰、礼物和食物图标。食物及部分礼物图标用 ImageGen 离线制作，运行时直接加载 PNG。 |
| [voices/](../voices/) 与 [voice_manifest.json](../voice_manifest.json) | 原始 OGG、本地语音指南与 CSV。运行时清单记录语音 ID、来源、字幕、时长、分级和场景。素材许可见 [README](../README.md#素材版权说明)。 |

提醒到期使用排程修订号区分不同次触发，通知用唯一键防重复。当日礼物使用 `daily:YYYY-MM-DD` 奖励包，游戏奖励包用游戏类型和对局 ID 标识。翻牌重复调用只返回已经领取的结果。修改这些功能时沿用服务层和 `Storage.transaction()`，让状态更新和去重在同一事务中完成。

## 修改入口与验证

- **改界面**时先看 `ui_theme.py` 与 `ui_widgets.py`，再定位对应页面。桌宠右键菜单在 `window.py`。事项提醒的新建入口是 `AssistantPanel._add_reminder()`，表单时间转换和提醒服务都要覆盖。
- **改桌宠动作**时先看 `Behaviors`、`PetScene` 和动画清单。检查序列帧能从菜单点播、按下时可打断，且鼠标命中与当前画面一致。
- **改语音**时先确定是通用场景、互动事件还是日历事件，再检查 `voice_manifest.json`、`interaction_feedback.py` 或 `calendar_events.py`。用语音 ID 引用真实 OGG 和对应译文，沿用音频与勿扰策略。参见 [语音全量分类与功能调用指南](../voices/凯伊桌宠_语音全量分类与功能调用指南.md)。
- **改业务规则或数据**时从 `AssistantController` 和表格中的服务入口追踪。测试优先使用临时数据库或 `:memory:`，检查正常流程、重复触发和重启恢复。

在项目根目录运行以下现有检查，可按修改范围选择对应一组。渲染、语音和素材校验用例需要完整本地素材。

```powershell
python -m unittest tools.test_behaviors tools.test_gestures tools.test_animations tools.test_window
python -m unittest tools.test_assistant_services tools.test_assistant_controller tools.test_assistant_panel
python -m unittest tools.test_interaction tools.test_companion tools.test_companion_pages tools.test_shortcuts
python -m unittest tools.test_audio tools.test_voice_manifest
```

调整动作素材时，可用 `python tools/verify_animation_assets.py` 检查序列帧。离屏测试覆盖逻辑和基础界面行为。原生透明窗鼠标穿透、托盘、跨屏缩放、真实声音输出和全屏勿扰仍需在 Windows 桌面上验收。
