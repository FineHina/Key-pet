# 凯伊桌宠：语音与音效需求清单

> 编制日期：2026-11-24  
> 状态：音频设计与备料清单，尚未录制、采购或实现音频功能。  
> 关联设计：[额外功能设计与实现路线](额外功能设计与实现路线.md)。  
> 本地音频优先；所有示例台词均为待确认草案，不是原作官方台词。

## 1. 声音设计目标

角色声音用于补充“原立绘差分 + 文字 + 动作”，不要让每次点击都成为噪声。风格建议：平常克制、语速自然；开心时更明亮；不好意思与害羞时短暂停顿；生气强调边界而不吼叫；哭泣只在用户主动选择或明确游戏情境使用，不随机制造负面压力。

角色身份不等于配音授权。优先采用有使用授权的现成音频、委托配音或具备使用授权的TTS音色；不得未经同意克隆真实配音演员或其他真人的声音。公开发布前记录素材来源、许可及商用/再分发范围。

## 2. 与现有原立绘和动作的对应

| 图文类别 | 原立绘编号 | 主要现有触发 | 语音方向 |
|---|---|---|---|
| 默认 | 01–05 | 手动查看、普通问候 | 简短回应、平静招呼 |
| 微笑 | 07–10 | 单击头部/身体 | 温和回应、认可 |
| 开心大笑 | 14–15 | 双击头部；身体双击动作1 | 开心答应、短笑或鼓励 |
| 不好意思 | 12 | 悬停、拖拽反应 | 稍犹豫的询问 |
| 生气黑脸 | 23 | 连续戳到较高阈值 | 低、短、克制地警告 |
| 生气 | 24–25 | 连续戳动 | 明确但轻度制止 |
| 害羞 | 26–28 | 头部长按 | 放轻声音、带停顿 |
| 哭泣 | 29–31 | 手动查看，后续明确游戏情境 | 极短哭腔，不循环哭声 |

**不要求21张立绘各配一套语音。** 先按8个情绪类别建立共享台词池，同一次反应选择一句台词，再绑定该句的音频和同类原图。文字必须对应正在播放的台词，不能图片、文字、语音各自随机。

四段视频动作：
- 待机动画2、待机动作：默认无音轨，不因呼吸或轻微动作持续发声。
- 动作1：身体双击时可选一条开心/动作起始语音，不给10.7秒整段动作填满对白；取消后及时停止。
- 原地行走：默认无声；脚步音为后期可选，低音量且不持续扰人。

| VO_REMINDER_01–04 | 4 | F02提醒：到期、稍后、完成、便签保存 | “你设的提醒到时间了。” / “好，稍后再提醒。” / “这件事完成了。” / “记下来了。” |

| VO_CARE_01–04 | 4 | F04/F05好感度/喂食：感谢、开心、冷却、互动邀请 | “谢谢你。” / “这个不错。” / “等一会儿再来吧。” / “要一起玩一会儿吗？” |
| VO_GAME_01–05 | 5 | F06猜拳：开始、赢、输、平局、结束 | “来猜拳吧。” / “这次是我赢了。” / “这次你赢啦。” / “平局，再来一次？” / “下次再玩。” |

固定提醒语音与动态事项分开：角色只说“提醒到时间了”，事项显示文字。读取私人事项或AI回复的TTS是另一个后期能力，需用户选择；不默认把事项发送到云端。

### 3.3 台词与字幕规则

- `(微笑)`、`(开心地跳了一下)`、`(黑脸盯着你)`等舞台说明**不朗读**；它们是视觉行为描述，不是对白。
- 录音字幕使用实际说出的文本，允许明确的短笑标注如“嘿嘿”，不能音频说A而卡片随机显示B。
- 委托配音先确认整套措辞、读音、情绪强度和角色称呼；未确认之前示例台词不当作定稿。
- 动态事项、日期、文件路径默认只显示文字，避免大量录制组合句。

## 4. 音效清单

### 4.1 首批核心音效：9个

| ID | 场景 | 建议时长 | 设计与限制 |
|---|---|---:|---|
| SFX_TOUCH | 轻点/摸头 | 0.05–0.15s | 柔软小提示；有语音时可不播放，不是每次点击都必须有 |
| SFX_CARD_OPEN | 图文卡片出现 | 0.08–0.18s | 轻微纸片/弹出音；默认可关闭，与TOUCH二选一 |
| SFX_DRAG_LIFT | 拖起 | 0.10–0.25s | 很轻的提起音，拖拽冷却 |
| SFX_LAND | 松手落地 | 0.10–0.25s | 柔软落地，不能像重物砸落 |
| SFX_TIMER_START | 专注开始 | 0.10–0.35s | 确认提示；不同时叠语音和另一确认音 |
| SFX_TIMER_END | 专注/休息结束 | 0.4–1.0s | 两音柔和铃，默认一次 |
| SFX_REMINDER | 提醒到期 | 0.5–1.2s | 可辨认但不刺耳，不循环催促 |
| SFX_CONFIRM | 保存、确认、完成 | 0.08–0.25s | 复用于便签/稍后提醒/设置 |
| SFX_ERROR | 找不到路径、操作失败 | 0.10–0.35s | 温和错误音；不要使用系统警报式尖声 |

| SFX_GAME_LOSE | 结果输 | 0.2–0.6s | 轻松、不羞辱用户 |

建议**25条首批语音 + 9个核心音效**先备料；完整扩展预算为**51条语音 + 16个音效，共67个候选素材**。这不是必须全部录制的上线门槛，可共用确认音和去掉不必要音效。

## 5. 不需要的音频

- 不给呼吸、光环浮动、眨眼、鼠标路过持续配音。
- 不从黑底录屏自动提取未知音轨作为可再分发素材；检查来源和许可后再决定。
- 不播放循环哭泣、持续生气、每秒脚步、每条聊天“收到”的高频提示。
- 暂不需要背景音乐。常驻桌宠应尊重用户正在播放的音乐和工作。
- 没有相应画面，不制作挥武器、碰撞、战斗音效；当前桌宠为无武器表现。

## 6. 声音触发、配对和队列

### 6.1 配对事件

一次反应应包含：反应ID、表情类别、原图ID、实际台词、voice_id、可选sfx_id、动作ID、触发来源、优先级与到期时间。先选择台词，再从同一条目得到音频，禁止三套独立随机池。

建议后续台词条目（示意，仅文档，不修改现有配置）：

```json
{
  "id": "smile_greeting_01",
  "category": "smile",
  "text": "嗯，我在。",
  "voice_id": "VO_SMILE_01",
  "sfx_id": null,
  "source_image_ids": [7, 8, 9, 10],
  "cooldown_seconds": 8
}
```

### 6.2 节流建议

- 轻点提示音：至少间隔0.4秒；连续快速点击合并，不积压。
- 普通互动语音：至少间隔3–6秒；未播完时优先保留当前或用高优先级替换，不能每点一次排队一句。
- 同一台词：尽量60秒内不重复；素材池不足则静默，不一定换句硬播。
- 悬停语音：每次进入最多一次，并建议20秒冷却；默认低概率或只图文。
- 拖起/落地：2秒左右冷却；高频拖动不配每个落点。
- 问候/休息提醒：按时段和任务ID去重。
- 手动“试听”不受普通随机概率影响，但仍只播一条，且可停止。

### 6.3 优先级与打断

到期提醒 > 用户主动请求的语音/当前游戏结果 > 普通点击反应 > 低频问候/待机。

同一时刻最多一条角色语音。非关键音效可低音量搭配，但核心通知建议先短提示音、再语音，而非同时轰鸣。高优先级通知可对低优先级语音做约80–150ms淡出。勿扰/静音/退出立即停止；过期反应不补播。

普通图文约5秒：首批短语音应在该窗口内结束。后续长TTS使用独立对话窗口或显示与播放同步的生命周期，不让图片先消失而语音继续无来源地播放。

## 7. 录制、音频格式与交付规范

### 7.1 母版与运行文件

- 配音母版：WAV、单声道、48kHz、24bit PCM，干声，不带音乐/混响。
- 运行语音：WAV 48kHz/16bit 单声道（第一版最简单）；如以后压缩，用Qt实际部署环境验证格式后统一转换。
- 短音效：WAV、48kHz/16bit PCM，通常单声道。QSoundEffect使用已验证WAV，不能仅改扩展名。
- 语音开头静音建议50–120ms，结尾100–250ms；音效首尾做很短淡入淡出避免点击噪声。
- 配音与音效分开文件，不把UI音混在台词里，便于独立音量和静音。
- 试音后统一感知响度；建议语音约−18 LUFS-I，true peak不高于−1dBTP，音效按听感低于语音。超短音效LUFS值仅作参考，不能为了达到指标放大噪声。

### 7.2 命名与目录（建议，尚未创建音频资产）

```text
assets/audio/
  voices/zh-CN/VO_SMILE_01.wav
  voices/zh-CN/VO_FOCUS_04.wav
  sfx/SFX_REMINDER.wav
  audio_manifest.json
```

清单字段建议：ID、文件、实际字幕、情绪、场景、时长、响度、优先级、冷却、作者、来源、授权、版本、是否允许再分发。文件名不使用不稳定随机序号，方便换素材而不改触发代码。

### 7.3 配音委托交付

每条提供：台词、上下文、情绪、可用时长、2–3种强度选择和禁止事项。先试录默认/微笑/害羞/生气各一条，确认听感后再批量录制。需求中明确不要求模仿未经授权的真实演员。

## 8. 后续实现方案

新增音频服务（仅设计）：统一接收反应事件，查音频清单，执行勿扰、音量、优先级、去重与队列。短WAV音效走QSoundEffect；语音走Qt Multimedia。所有网络TTS在工作线程完成，取消与回调按反应ID关联，过期回调丢弃。

图文与音频有同一反应ID，来源是现有点击/长按/连戳和后续F01–F08功能事件。卡片仍鼠标穿透，试听、播放/停止、音量设置放独立可操作设置窗口。

缺少音频时继续原立绘+文字，不能阻塞界面。默认不联网合成，也不读取私人提醒内容用于上传。随机语音概率、总音量、语音与音效开关分开设置。

## 9. 素材验收表

1. 字幕与实际台词一致，舞台说明未朗读，中文读音正确。
2. 图文表情与情绪匹配，黑脸和哭泣不会在正常待机随机出现。
3. 录音无爆音、削波、长底噪、突兀混响；音量切换一致。
4. 5秒卡片内短语音可结束，动作中断/静音/退出能停止。
5. 高速点击不叠语音，不排出几十条；到期提醒不丢失。
6. 休息/全屏/勿扰策略符合用户设置，默认脚步和待机无声。
7. 素材路径/缺文件/设备不可用可降级，Qt主线程不卡顿。
8. 每个素材授权明确，适用范围符合最终分发方式。

## 10. 下一步建议

先确定“是否要角色配音”与可用的授权来源，再试录4条基础情绪；音效先准备确认、提醒、计时结束3个。通过实际使用验证音量和打扰程度后，按第一阶段功能再扩充，不必一次采购67个素材。
