# 凯伊桌宠：额外功能设计与实现路线

> 编制日期：2026-11-24  
> 状态：第一阶段F01番茄钟、F02一次性提醒、F03勿扰及F09互动语音已实现；其余条目仍为设计。当前使用方法见[第一阶段使用说明](第一阶段使用说明.md)。本文保留后续路线，细项并非全部上线。  
> 配套文档：[语音与音效需求](语音与音效需求.md)。

## 1. 产品方向与现有基础

定位：**有情绪的陪伴角色 + 不打扰的轻量桌面助手**。

现有基础：透明置顶Q版桌宠、拖拽与缩放、托盘菜单、位置记忆、原立绘图文反应、四组视频动作。Q版保持原脸，情绪通过原立绘差分卡片表现，不再重绘Q版眉眼或嘴巴。行走只原地播放，不自动移动窗口。

原立绘分组：默认01–05；微笑07–10；大笑14–15；不好意思12；黑脸23；生气24–25；害羞26–28；哭泣29–31。图文反应默认5秒。图片默认约108×108px，文字14px；卡片优先居中显示在桌宠正上方，上方不足时向下避让并限制在屏幕内。

## 2. 设计原则

- 本地优先：第一阶段不需要联网、账号、麦克风或AI服务。
- 不打扰：主动弹窗、声音和待机都有冷却；支持静音、勿扰和全屏抑制。
- 操作与展示分离：现有图文卡片鼠标穿透，仅用于展示；表单、小游戏、提醒确认另用可操作窗口。
- 不强制移动桌宠，不自行读取屏幕、剪贴板和私人文件。
- 轻量运行：Qt主线程只处理界面；网络、语音生成等耗时操作放工作线程。
- 可取消：计时、提醒、对话和声音都提供关闭或取消入口。
- 艺术约束：使用已确认的原立绘和动作，不引入未经确认的Q版重绘。

## 3. 功能清单

### F01 番茄钟与专注陪伴｜第一阶段

**体验**：右键「开始专注」，选择25/45/60分钟或自定义时间。桌宠进入安静待机；结束时微笑或开心原立绘配合祝贺文字。支持暂停、继续、取消和5/10分钟休息。

**实现**：独立计时服务，使用单调时钟计算当前会话剩余时间，Qt定时器只刷新显示。重启恢复需保存绝对截止时间和状态，校验系统时间变动；电脑睡眠后先按实际时间校正，不能靠递减整数计时。

**数据**：会话ID、开始/截止时间、已暂停时长、状态、是否完成、是否已提醒。可选保存本地专注统计。

**验收**：暂停不偷走时间；取消不会在原截止时间提醒；一次结束只触发一次；睡眠唤醒正确；勿扰时视觉/声音遵循设置。

### F02 自定义提醒与便签｜第一阶段

**体验**：用小表单选择“多少分钟后”或具体时间，输入事项；到点显示角色图片和事项，提供「完成」「稍后提醒」。便签可创建、编辑、删除。

**实现**：提醒服务+SQLite存储，启动、唤醒时扫描未完成任务。第一版不用自然语言解析；“半小时后提醒我”可后续用本地规则解析，避免为简单提醒引入AI。

**重要区别**：普通摸头反应5秒后消失；提醒要使用独立可交互窗口，确认后才关闭，不能只弹5秒然后丢失。

**验收**：重启不丢任务；过期任务不会重复弹出；稍后提醒更新到正确时间；删除/取消需明确操作；显示文字长度有上限并支持滚动。

### F03 勿扰、静音与全屏策略｜第一阶段基础能力

**体验**：托盘一键勿扰，分别控制主动弹窗、角色语音、提示音；设置夜间时段。勿扰期间主动点击仍可有无声图文反应。

**实现**：统一通知策略服务。优先服从手动勿扰；然后处理时段和全屏前台检测。重要提醒可以进入待查看列表，不默认越过勿扰发声。

**验收**：开启后不再主动播放声音；进入全屏不会刷屏；退出勿扰不补播大量旧通知；手动点击仍响应。

### F04 好感度与心情｜第二阶段

**体验**：摸头、完成专注、小游戏获得温和积极反馈；连戳暂时生气。数值影响台词和反应概率，而不是锁住基础功能。

**实现**：角色状态服务，维护亲密度、心情、最近互动、每日增益和冷却。规则配置与素材选择分离；数值范围明确，每类事件按日限额，防止重复点击刷分。

**约束**：离开电脑或长期未启动不惩罚；不让角色持续饥饿、生气或哭泣；不向用户施加照顾压力。

**验收**：同一事件只计一次；状态重启可恢复；连戳停止后自动缓和；状态变化不覆盖提醒。

### F05 喂食与照顾｜第二阶段

**体验**：菜单选择小零食或饮料，出现开心/害羞原立绘和短反应；偶尔询问是否互动，可忽略。

**实现**：本地物品表、冷却记录、可选虚拟积分。动作先复用已有视频，不在没有素材时硬做咀嚼或吞咽动画。

**验收**：冷却稳定；取消不会扣物品；离线不惩罚；与专注/勿扰模式不冲突。

### F06 轻量小游戏｜第二阶段

**首选**：猜拳，其次猜数字、抽签。使用独立小窗口；角色输赢用不同原立绘和台词响应。

**实现**：每个游戏为独立状态机，规则在本地运行；输入、结果、退出通过事件总线。抽签明确是娱乐，不作为医疗、财务等现实决策依据。

**验收**：结果生成不受连续点击改变；退出能释放状态；不留下计时器；结果只通知一次；用户正在输入时待机不能抢焦点。

### F07 日常陪伴对话｜第三阶段

**第一版**：离线问候、鼓励、时间台词和关键词话题；配合默认/微笑/害羞等原立绘。避免连续重复，同一话题有多条短回复。

**后续可选AI**：独立输入窗口、用户明确发送；网络请求放工作线程，支持取消、超时和错误提示。API密钥放系统凭据存储，不写日志或明文配置；明确费用与发送内容。

**隐私**：默认不截屏，不读剪贴板，不扫描文件，不采集麦克风。联网对话或语音合成前说明数据会发送到哪个服务。

**验收**：离线模式无网络请求；网络不可用不冻结；重发不重复扣费；聊天保存可关闭/清除；回复不覆盖正在编辑的输入。

### F08 快捷工具入口｜第三阶段

**体验**：托盘里打开常用应用、文件夹、网页或便签，用户自己配置。

**实现**：调用系统打开接口，优先使用Qt桌面服务。第一版只“打开”，不接受任意Shell命令，不删除文件、不默认代替用户执行敏感操作。

**验收**：不存在的路径给出提示；特殊字符路径正确；执行高风险操作必须另行确认；快捷项可以撤销和编辑。

### F09 语音与音效｜跨阶段可选

**体验**：短互动语音、提醒提示音、游戏反馈，提供总音量和分项开关。素材需求见[语音与音效需求](语音与音效需求.md)。

**实现**：短音效用QSoundEffect，本地较长语音用Qt Multimedia；统一音频队列、优先级、冷却与勿扰策略。TTS留作后续可选，不做未经授权的真人声音克隆。

**验收**：语音不重叠，连戳不刷音效，静音即时生效，暂停/退出会停止播放，缺文件时图文仍正常。

## 4. 建议实施顺序

| 阶段 | 功能 | 交付目标 |
|---|---|---|
| 1 | F03基础策略 + F01专注 + F02提醒便签 | 有用、安静、可暂停取消、重启不丢任务 |
| 2 | F04状态 + F05喂食 + F06猜拳 | 角色反馈更丰富但不强迫照顾 |
| 3 | F07本地对话 → 可选AI + F08快捷项 | 扩展互动入口，网络能力明确授权 |
| 贯穿 | F09音频 | 先少量本地语音/音效，验证不打扰后再扩充 |

建议先完成第一阶段，再增加养成。不要一次将聊天、养成、计时、自动化都堆进窗口类。

## 5. 架构与事件方案

```text
鼠标 / 菜单 / 表单
      ↓
功能服务（计时、提醒、游戏、角色状态）
      ↓
事件总线 + 通知策略 + 优先级
      ↓
原立绘图文卡片 / 可交互窗口 / 视频动作 / 音频队列
```

现有接入点：`pet/window.py`负责入口；`pet/behaviors.py`负责反应调度；`pet/bubbles.py`和`pet/reaction_card.py`负责原图文字；`pet/animations.py`负责视频帧。

后续建议新增（仅设计，未创建模块）：`services/focus.py`、`services/reminders.py`、`services/pet_state.py`、`services/notification_policy.py`、`services/audio.py`、`games/rps.py`。功能模块不直接移动桌宠或修改其他模块状态。

事件示例：`focus.started/completed`、`reminder.due/snoozed`、`pet.fed`、`game.result`、`dialog.reply`。事件可包含ID、来源、优先级、表情类别、文字、动作ID、语音ID、音效ID、过期时间。动态提醒/AI内容必须当作文本处理，不能解释为命令。

## 6. 优先级与状态互斥

- 拖拽、用户当前输入/小游戏操作有最高操作优先级；不抢焦点，不强行关闭。
- 到期提醒进入可交互通知，不能被摸头图文覆盖；多个提醒排队合并。
- 当前游戏/对话结果高于普通摸头反馈，普通反馈高于随机待机。
- 视频动作可被用户主动输入立即打断；通知卡片与动作之间要避免重复反应。
- 音频、图片、文字须使用同一个反应ID；重复事件去重，过期后不再播放旧语音。
- 持续通知不要通过一直循环语音催促用户。

## 7. 存储、设置与权限

现有位置/大小配置保留；结构化功能数据优先SQLite。建议记录提醒、专注会话、角色状态、物品和可选小游戏成绩。涉及删除的数据操作应可确认或撤销。

设置建议：总音量、语音/音效分项、勿扰时段、全屏策略、主动互动频率、提醒强度、是否保存聊天、是否允许联网。新增设置需要版本迁移和默认值，不能破坏旧配置。

## 8. 后续测试清单

1. 定时、睡眠唤醒、系统时间变化、重启恢复和去重。
2. 提醒不会被随机待机、摸头或音频覆盖。
3. 原立绘编号匹配，Q版保持原脸，原地行走不移动窗口。
4. 可交互窗口与鼠标穿透卡片各自正确，拖拽缩放和多屏边界不退化。
5. 勿扰/静音/退出即时停止主动提示，无积压补播。
6. 网络、声音文件和源图缺失时给出清晰降级；Qt主线程不阻塞。
7. SQLite迁移、取消/稍后、数据清除和退出释放资源。

## 9. 当前结论

本文保留后续功能路线。**第一阶段已加入番茄钟、一次性持久提醒、勿扰模式和本地互动语音**；F04–F08养成、小游戏、对话、快捷入口以及独立音效等仍未实现。实际入口、限制和测试见[第一阶段使用说明](第一阶段使用说明.md)。原图卡片位置与默认108px图片保持不变。
