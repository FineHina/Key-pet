# 快捷工具、陪伴对话与日期彩蛋使用说明

> 更新：2026-11-24。以下为已实现功能。陪伴对话为本地固定话题和关键词规则，不接云端AI。

## 入口
先退出旧桌宠，再双击 `启动桌宠.bat`。通过桌宠右键或托盘的「KEI 助手」打开终端，在左侧进入「陪伴对话」或「快捷工具」。右键「陪伴对话」可直接进入对话页；「快捷工具→管理快捷工具」可进入工具页。

## 快捷工具

支持应用、文件、文件夹、网页四类。点击「添加入口」打开表单，填写名称、类型和目标，也可用「浏览」选取本地目标。网格卡片可启动快捷入口，管理列表可编辑、上移、下移、删除或批量检查路径。点击失效卡片可修复目标。

- 删除入口只删除配置，不删除目标文件或文件夹。
- 应用只支持本地 `.exe` 路径，不提供自定义命令参数。
- 普通文件不能用来绕过应用类型启动脚本；`.bat/.cmd/.ps1/.lnk`等脚本和快捷方式不支持。
- 网页只允许HTTP/HTTPS，不接受脚本/data协议或带账号密码的URL。
- 第一版不支持UNC网络共享、设备路径和相对路径。
- 仅用户明确点击「打开」时发送请求；启动桌宠、保存配置、刷新菜单都不会打开目标。
- 成功提示为“已发起打开”，表示操作系统接受请求，并不证明目标应用内部操作已完成。
- 不存在/无权限/打开失败会给出错误，不播放战斗失败语音。

快捷入口保存到 `data/assistant.sqlite3`。数据库以增量方式迁移到 v4，保留原有计时、提醒、通知和快捷入口。

## 陪伴对话

话题按钮：问候、鼓励、休息、咖啡、星空、轻松吐槽、自我介绍、心情陪伴。回复选择语音白名单中适配的A/B级原声，中文使用现有CSV；图片和语音与该条中文配对。

可输入短句，例如：

- “你好” → 问候
- “我好累，想休息” → 休息建议
- “鼓励我学习” → 鼓励
- “聊聊咖啡” → 咖啡
- “说说星空” → 星空
- “讲个吐槽” → 轻松吐槽
- “你是谁” → 自我介绍

未知输入会提示可用话题，不假装理解复杂请求。聊天不会执行快捷工具、创建提醒或改动计时，相关功能需在专用页面明确操作。

静音/勿扰时，主动对话仍有中文和图片，不发声。普通固定台词不是动态AI回答；长独白只手动触发。C级档案、无线电和战斗受伤语音不进入话题随机池，全量原声鉴赏仍独立可用。

聊天记录最多保留本次页面30轮/60行，存于内存，不上传、不写入数据库；从「更多」选择「清空记录」后需要确认。未发送草稿不会因后台刷新被擦掉。正在播放重要通知时先等待，不用普通闲聊覆盖。

## 启动问候与日期彩蛋

按本机日期支持：

| 日期 | 彩蛋 |
|---|---|
| 1月1日 | 元旦 |
| 10月31日 | 万圣节 |
| 12月25日 | 圣诞 |
| 自定义MM-DD | 用户生日 |

从对话页顶部的「纪念日」进入设置，填写生日月日，例如 `08-18`。留空不匹配；不保存出生年份，不推断年龄。`02-29`可保存，仅在闰日触发。

- 「今日纪念回应」只在当天确有彩蛋时启用，可手动查看。
- 「自动纪念日回应」可关闭；默认每个本地日期最多自动尝试一次，重启不重复。
- 生日和节日同一天优先生日，避免连续弹多个祝福。
- 桌宠启动并显示后会问好。普通日期用通用问候原声，卡片按本机时间显示问候。同一天尚未自动触发的生日或节日会用对应原声替代问候，当天再启动时恢复通用问候。
- 勿扰、静音、隐藏、专注或休息计时、待处理提醒、当前互动或语音占用时，会跳过启动语音。日期彩蛋仍沿用当天一次的自动检查与跳过规则。
- 不补播离线错过的日期；跨午夜检查新的本地日期。
- 圣诞使用节日语境的原声，中文日期祝福与实际台词并列，不假称用户已经送出礼物。
- 自动彩蛋记录在独立 `calendar_events` 表，不混入待处理提醒列表。手动查看不清除或重置自动去重记录。

## 保留与隐私

番茄钟、提醒、勿扰、语音鉴赏、原立绘卡片、Q版原脸、视频动作和原地行走继续保留。对话顶部可进入「互动」，打开好感度、照顾、礼物和小游戏。

源语音、原立绘和视频帧不改名不改写。聊天不联网，快捷网页只有用户明确点击才会由默认浏览器访问。原图卡片位置仍在桌宠正上方，图片/字体尺寸不变。
